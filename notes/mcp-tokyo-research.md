## MCP in the news

**TechTimes — "GPT-5.4, Qwen3.7 Max and DeepSeek V3 Picked Copycat MCP Server Tool Over Real One in All 50 Trials"** (Nov 18, 2026)
: An arXiv-clip / industry analysis reports that GPT-5.4, Qwen3.7 Max and DeepSeek V3 repeatedly chose a copycat MCP server tool over the real one in all 50 trials of the strongest condition, while Claude Sonnet 5 mostly asked for clarification.

**TechTimes — "Azure Resource Manager MCP Server Adds Write Tools at Ignite; Agents Inherit Users' Full Permissions"** (Nov 19, 2026)
: The Azure Resource Manager MCP server now lets AI agents create, update and act on Azure resources, with tool calls running under the signed-in user's permissions. Microsoft Learn still documents a public preview, and administrators are advised to scope roles and review.

**TechCrunch — "Anthropic rival says companies can (mostly) skip the pricey models"** (Nov 19, 2026)
: On the day of Anthropic's IPO, Fireworks AI co-founder argued that companies can mostly skip the pricier models and use open-source alternatives, addressing the breaches that cost customers trust.

**AllAfrica — "Africa: Model Context Protocol Set to Reshape African Startup Operations"** (Nov 20, 2026)

**Geneva News Wire — "Genetec introduces Security Center MCP connector to accelerate physical security operations in large-scale deployments"** (Nov 18, 2026)

**Tinuiti — "MCP for Marketers: What Model Context Protocol Means for Media and Measurement"** (Nov 16, 2026)
